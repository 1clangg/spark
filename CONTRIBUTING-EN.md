# Contributing to Spark Linux

Spark Linux is an open-source operating system project developed in Vietnam, focused on being lightweight, modern, and stable.

We welcome all contributions from the community — whether you're a beginner or an experienced developer.

---

## How you can contribute

You can help Spark Linux by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Fixing system issues
* Optimizing performance
* Contributing scripts, themes, or tools

---

## General Guidelines

Before contributing, please ensure that you:

* Understand the goal of Spark Linux (lightweight, fast, minimal)
* Avoid adding unnecessary components (bloat)
* Keep code simple, readable, and maintainable
* Respect the existing project structure
* Test your changes before submitting a Pull Request

---

## Contribution Workflow

### 1. Fork the repository

Create your own fork of the Spark Linux repository on GitHub.

---

### 2. Clone your fork

```bash id="p1x7aa"
git clone https://github.com/your-username/spark.git
cd spark
```

---

### 3. Create a new branch

```bash id="b8q2zx"
git checkout -b feature/your-feature-name
```

---

### 4. Make your changes

* Keep changes focused and minimal
* Avoid unrelated modifications in a single PR

---

### 5. Commit properly

Use clear commit messages:

* `fix:` bug fixes
* `add:` new features
* `update:` improvements
* `remove:` deletions

Example:

```bash id="m4k9lp"
git commit -m "fix: improve boot performance on low-end devices"
```

---

### 6. Push and create a Pull Request

```bash id="z7c3aa"
git push origin feature/your-feature-name
```

Then open a Pull Request on GitHub.

---

## Pull Request Requirements

A pull request will only be merged if it:

* Does not break existing functionality
* Has a clear and meaningful description
* Is clean and easy to review
* Does not introduce unnecessary bloat
* Has a valid reason for the change

---


## Need Help?

If you're unsure:

* Open an issue before making large changes
* Discuss in the pull request
* Ask maintainers for guidance

---

## Code of Conduct

All contributions must follow the project's Code of Conduct.
