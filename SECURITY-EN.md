# Security Policy – Spark Linux

Security is a core part of the Spark Linux system. We continuously work to maintain a safe, stable, and reliable environment for all users.

---

## Supported Versions

Spark Linux only provides security support for actively maintained and officially released versions.

| Version                             | Status                 |
| ----------------------------------- | ---------------------- |
| Spark Linux 3.0 (Debian 13.5)       | ✅ Supported            |
| sparkNext Developer (Debian 14)     | ⚠️ Subject to change   |
| Spark Linux 1.0 & 2.0 (Debian 12.0) | ⚠️ End of support soon |

> ⚠️ Older versions may not receive security updates. Users are strongly encouraged to upgrade to the latest stable release.

---

## Reporting a Vulnerability

If you discover a security vulnerability in Spark Linux, please report it as follows:

* **Contact email:** security@spark-linux (or official project security contact)
* **Subject line:** `[SECURITY] Spark Linux Vulnerability Report`

---

## What to include in your report

To help us respond quickly and effectively, please include:

* A detailed description of the vulnerability
* Steps to reproduce the issue
* Spark Linux version affected
* Potential impact assessment (if known)
* Screenshots, logs, or supporting materials

---

## Response process

After receiving a report, we will:

* Acknowledge the report within 48–72 hours
* Investigate and assess severity
* Develop and release a fix if necessary
* Publish a public disclosure after the issue is resolved (when appropriate)

---

## Security principles

* Do not publicly disclose vulnerabilities before a fix is available
* Do not exploit vulnerabilities to harm users or systems
* Work with maintainers to improve overall system security

---

## Note

Spark Linux is built on a simple principle:

> “Security must go hand in hand with performance and simplicity.”

We greatly appreciate all contributions that help improve system security.
